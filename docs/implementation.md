# Algorithms and tests
Apriori: singleton support → frequent set → candidate combinations → support pruning → association rules.
Tree: label entropy → conditional entropy / split information → gain ratio → recursive split → leaf classification.
Fallback은 descendant leaf 다수결이므로 training row-weighted majority와 다릅니다. Synthetic checks는 support 및 간단한 분류를 검증하며 benchmark 재현이나 overfitting 해소를 주장하지 않습니다.
